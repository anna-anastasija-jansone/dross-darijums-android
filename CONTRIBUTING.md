# Contributing

1. Pull the latest `main`.
2. Create a short-lived branch using `feature/`, `fix/`, or `docs/`.
3. Make focused commits with clear messages.
4. Push the branch and open a pull request.
5. One teammate reviews the code and leaves three concrete inline comments.
6. Another teammate checks branch names, commit messages, `.gitignore`, secrets, CI, and Definition of Done.
7. Merge only after the agreed acceptance criteria are met.
